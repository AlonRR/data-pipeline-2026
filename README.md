# Data Pipelines Workshop — 2026

Repository for course materials for Shenkar's Data Pipelines Workshop (course 3500834).

The course covers:

1. Data pipelines and the development environment
2. Web scraping and crawling
3. APIs and structured data collection
4. Data cleaning, enrichment, and storage
5. Docker, Docker Compose, and Kubernetes
6. High-scale architecture, reliability, and observability
7. Final project: architecture review, load testing, and presentation

Course materials will be added here during the semester.

## Student preparation

During the first class, we will complete the [Student Setup Guide](docs/student-setup-guide.md) together.
